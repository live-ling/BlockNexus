# 前端重构设计基线（2026-10-21，分支 `refactor/frontend-redesign`）

> 本文是 F1 之前的**设计确认稿**：先定「有哪些页面、每页干什么、怎么排、用什么组件」，
> 再写原型，最后逐页接数据。**本轮不改现有页面代码**。
>
> 依据：`docs/frontend-redesign-audit.md`（盘点）、`docs/instance-page-refactor.md`（实例页）、
> `docs/frontend-redesign-handoff.md`（交接），以及当前 `web/src` 代码。

## 0. 一句话方向

**这是桌面应用，不是网站。** 窗口 1280×800（最小 960×640，外壳 WinForms 原生标题栏），
内容从窗口左边贴到右边，结构靠**固定区域 + 分隔线 + 密集表格**，不靠居中窄栏和大段留白。

**2026-10-21 已确认的五个方向**（据此做出 `/proto` 原型，见 §7）：

| 项 | 结论 |
|---|---|
| 导航壳 | 固定左侧栏 208（可折到 56）+ PageHeader 52 + 状态栏 28 |
| 列表首屏 | 密集表格为主，保留「表格 / 卡片」切换 |
| 实例页主区 | Tab 工作台（概览/终端/玩家/文件/配置/自动化/备份）+ 底部终端 Dock 全宽 |
| 密度 | 紧凑：正文 13px、表格行 30、区块间距 8、面板内边距 12 |
| 原型形态 | app 内隐藏路由 `/proto`，真实 shadcn 组件 + mock 数据 |

与现状最直观的四个差别：

| 现状（网页思维） | 目标（应用思维） |
|---|---|
| `mx-auto max-w-5xl/[1400px] px-5 pt-7 pb-28` 居中窄栏 | 全宽铺满，页面内边距 16，无 `pb-28` 底部空档 |
| 卡片网格 `minmax(300~320px,1fr)`，宽屏碎成窄长卡 | 数据表 / 主从双栏 / 分区面板；一列到底或 240 侧栏 |
| 底部悬浮胶囊导航（手机味） | 固定左侧栏 208（可折到 56）＋ 底部状态栏 28 |
| 空态 `py-16` 大留白、区块间 `gap-5` | 空态一行文案＋操作；区块间 8，字段间 4~6 |

**保留不动**：shadcn/Radix + Tailwind、现有配色与字体（Geist）、虚拟滚动/日志组件、所有后端接口。

## 1. 窗口骨架（AppShell）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ PageHeader  52px   标题 · 面包屑 · 页面级操作            [⌘K 搜索]  [快速添加] │
├──────────┬───────────────────────────────────────────────────────────────────┤
│ Rail 208 │ 内容区 padding 12~16，全宽，独立滚动                              │
│ ◆ 实例   │                                                                   │
│   服务器 │  ListPage   : 工具栏 40 + 表格（行高 30）                          │
│   设置   │  DetailPage : 指标条 64 + Tab 36 + 主从区 + Dock                  │
│          │  SettingsPage: 子导航 190 + 表单区 + 粘性保存条                    │
│ ─────    │                                                                   │
│ 用户/退出│                                                                   │
├──────────┴───────────────────────────────────────────────────────────────────┤
│ StatusBar 28px   ●SSE · 在线 2/3 · 任务 1（安装 62%）· v0.6.0 有更新 · 时区     │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **无自绘标题栏**：外壳用系统标题栏，网页里不再画一条假 titlebar（避免双标题栏）。
- **Rail**：图标＋文字，46px 行高，当前区高亮左侧 2px 竖条；底部固定「用户/退出/更新徽章」。
  窄屏（<1100）自动折成 56 图标栏，hover 出 tooltip。
- **PageHeader**：每页唯一，含返回（详情页）、标题、状态摘要、主操作；不再各页自写 `flex items-center gap-3`。
- **StatusBar**：全局常驻，承接现在散落的「SSE 状态 / 安装进度 / 版本徽章」——这些不该占页面正文。
- **危险横幅**（暴露且未开鉴权）仍置顶，但压到 24px 单行，不挡内容。

## 4. 尺寸与密度令牌

桌面应用的关键不是「小」，是**稳定、可预期、无空隙**。统一写进 `@theme`（Tailwind v4）与页面常量：

| 令牌 | 值 | 说明 |
|---|---|---|
| `--rail-w` | 208 / 56（折叠） | 左栏 |
| `--header-h` | 52 | PageHeader |
| `--toolbar-h` | 40 | 列表工具栏 |
| `--tab-h` | 36 | 页内 Tab |
| `--statusbar-h` | 28 | 底部状态栏 |
| `--row-h` | 30（紧凑）/ 36（标准） | 表格行 |
| `--pad-page` | 16 | 内容区外边距 |
| `--pad-panel` | 12 | 面板内边距 |
| `--gap-block` | 8 | 区块之间（现状 gap-5=20 太大） |
| `--gap-field` | 4~6 | 字段之间 |
| 字号 | 13 正文 / 11.5 次要 / 12 等宽数字 | 现状 14 正文偏网页 |
| 圆角 | 8（面板）/ 6（控件）/ 10（浮层） | 统一，不再混 12/16 |
| 分隔 | 1px `border-border`，不叠阴影 | 面板阴影只给浮层 |

**宽度策略**：列表与主从区吃满宽度，只在「表单字段组」限 `max-w-[720px]` 以保可读性；
禁止再出现「页面级 `max-w-*` + `mx-auto`」。

## 7. 原型（已落地：`/proto`）

打开方式：面板启动后访问 **`http://127.0.0.1:<端口>/proto`**（已登录/未登录都可以，原型不读登录态、不发请求）。
状态栏右下角的 `PROTO` 下拉可在六屏之间切换；真实应用里没有这一项。

| 文件 | 作用 |
|---|---|
