# 前端重构设计基线（2026-10-21，分支 `refactor/frontend-redesign`）

> 本文是 F1 之前的**设计确认稿**：先定「有哪些页面、每页干什么、怎么排、用什么组件」，
> 再写原型，最后逐页接数据。**本轮不改现有页面代码**。
>
> 依据：`docs/frontend-redesign-audit.md`（盘点）、`docs/instance-page-refactor.md`（实例页）、
> `docs/frontend-redesign-handoff.md`（交接），以及当前 `web/src` 代码。

## 0. 一句话方向

**这是桌面应用，不是网站。** 基准窗口 **1000×720**（外壳最小 960×640，系统原生标题栏），
内容从窗口左边贴到右边，结构靠**固定区域 + 分隔线 + 密集表格**，不靠居中窄栏和大段留白。

**已确认的六个方向**（2026-10-21 二次修订，据此做出 `/proto` 原型，见 §7）：

| 项 | 结论 |
|---|---|
| 导航 | **底部居中悬浮导航**（沿用现有 `ExpandableActionBar`），不做左侧栏；连接/任务/版本收进页头右侧状态簇 |
| 窗口基准 | **1000×720**（1000 宽时表格只画 6~7 列；宽过 1120 才补次要列） |
| 列表首屏 | 密集表格为主，保留「表格 / 卡片」切换；**列宽按内容给**，不靠拉宽列填满窗口 |
| 实例页主区 | Tab 工作台（概览/终端/玩家/文件/配置/自动化/备份）+ 底部终端 Dock 全宽 |
| 密度 | 正文 13px、表格行 **36**、工具栏 44、Tab 40、区块间距 8、面板内边距 12 |
| 删除 | **不设「危险」页**：删除就放在对象自己的页面里（实例→控制面板基础页底部；服务器→设置页末尾） |
| 原型形态 | app 内隐藏路由 `/proto`，真实 shadcn 组件 + mock 数据 |

与现状最直观的差别：

| 现状（网页思维） | 目标（应用思维） |
|---|---|
| `mx-auto max-w-5xl/[1400px] px-5 pt-7 pb-28` 居中窄栏 | 全宽铺满，页面内边距 16~20，滚动区底部只留悬浮导航的 80 |
| 卡片网格 `minmax(300~320px,1fr)`，宽屏碎成窄长卡 | 数据表 / 分区面板；列宽按内容，一列到底 |
| 搜索框、表单、资源列一律拉满可用宽度 | 搜索 224、表单组 620、资源列 140；**控件宽不过内容** |
| 底部悬浮胶囊导航（手机味，但好用） | 保留悬浮导航，只把状态信息挪进页头，不再额外压一条状态栏 |
| 空态 `py-16` 大留白、区块间 `gap-5` | 空态一行文案＋操作；区块间 8，字段间 6 |

**保留不动**：shadcn/Radix + Tailwind、现有配色与字体（Geist）、虚拟滚动/日志组件、所有后端接口。

## 1. 窗口骨架（AppShell）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ PageHeader 52px  标题 · 副标题              [页面操作] │ ●SSE 在线2/3 62% v0.6.0 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 内容区 padding 16~20，全宽，独立滚动（底部留 80 给悬浮导航）                  │
│  ListPage   : 工具栏 44 + 表格（行高 36，表头 32）                            │
│  DetailPage : 指标条 64（内容定宽）+ Tab 40 + 主从区 + Dock                   │
│  SettingsPage: 子导航 190 + 表单区（≤620）+ 粘性保存条                        │
│                                                                              │
│                   （底部居中悬浮导航：overlay，不占布局）                     │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **无自绘标题栏**：外壳用系统标题栏，网页里不再画一条假 titlebar（避免双标题栏）。
- **底部悬浮导航**：直接复用现有的 `ExpandableActionBar`（logo / 实例 / 服务器 / 设置），
  距底 20，`z-40`；内容滚动区留 `pb-20`，设置页给保存条上方留 64，避免被压住。
  实例工作台**不显示导航**（页面内有返回与终端），与现状一致。
- **PageHeader**：每页唯一，含返回（详情页）、标题、副标题、页面操作，最右侧是常驻状态簇
  （SSE / 在线数 / 安装进度 / 版本更新 / 原型切换器）。状态只做 11px 文本，宽度按内容。
- **不做底部状态栏**：悬浮导航已经在底部，再压一条 28px 状态栏在 1000×720 里太挤。
- **危险横幅**（暴露且未开鉴权）仍置顶，压到 24px 单行，不挡内容。

## 4. 尺寸与密度令牌

桌面应用的关键不是「小」，是**稳定、可预期、无空隙**。统一写进 `@theme`（Tailwind v4）与页面常量：

| 令牌 | 值 | 说明 |
|---|---|---|
| `--header-h` | 52 | PageHeader |
| `--toolbar-h` | 44 | 列表工具栏 |
| `--tab-h` | 40 | 页内 Tab |
| `--row-h` | 36（表格）/ 40（两行列表项） | 表格与列表行 |
| `--pad-page` | 16~20 | 内容区外边距 |
| `--pad-panel` | 12 | 面板内边距 |
| `--gap-block` | 8 | 区块之间（现状 gap-5=20 太大） |
| `--gap-field` | 6 | 字段之间 |
| `--nav-clear` | 80 | 悬浮导航让位（滚动区 `pb-20`；设置页保存条上方留 64） |
| `--form-w` | 620 | 设置表单组上限（两列各约 300） |
| 搜索框 | 224 | 不再拉满工具栏 |
| 字号 | 13 正文 / 11.5 次要 / 12 等宽数字 | 现状 14 正文偏网页 |
| 圆角 | 8（面板）/ 6~8（控件）/ 10（浮层） | 统一，不再混 12/16 |
| 分隔 | 1px `border-border`，不叠阴影 | 面板阴影只给浮层 |

**宽度策略**：列表吃满窗口，但**列宽按内容给**（只有名称列吸收剩余宽度）；
设置表单 ≤620；按钮/输入/资源条一律按内容定宽，不 `w-full` 拉满一列。
多余宽度留给空白，而不是把控件拉宽——「横向组件过宽」正是二次反馈里的主要问题。
**禁止**再出现「页面级 `max-w-*` + `mx-auto`」。

## 7. 原型（已落地：`/proto`）

打开方式：面板启动后访问 **`http://127.0.0.1:<端口>/proto`**（已登录/未登录都可以，原型不读登录态、不发请求）。
页头右侧状态簇里的 `PROTO` 下拉可在六屏之间切换；真实应用里没有这一项。

| 文件 | 作用 |
|---|---|
| `web/src/prototype/index.tsx` | 原型入口与屏幕切换 |
| `web/src/prototype/shell.tsx` | 悬浮导航 / PageHeader / 状态簇 / 屏幕切换器 |
| `web/src/prototype/proto-ui.tsx` | 原语：Panel / KV / Field / Toolbar / Segmented / EmptyState / SaveBar |
| `web/src/prototype/mock.ts` | 假数据（4 台服务器、7 个实例、玩家、日志、备份） |
| `web/src/prototype/screens/*.tsx` | 实例总览 / 服务器列表 / 服务器设置 / 实例工作台 / 面板设置 / 登录 |

要点：

- 全部用真实 shadcn 组件（Button/Dialog/Switch + 现有 `ExpandableActionBar`），不引入新依赖；
- **按 1000×720 设计**：表格在该宽度只画 6~7 列，宽过 1120 才补「核心/地址」「系统/延迟」；
- 实例工作台按最终形态呈现了两个已知症状的解法：**Dock 全宽**（收起 36px 仍可输入）、
  **控制面板 1160×760**（左导航 180 + 内容独立滚动 + 双列表单），破坏性动作在「基础」页底部；
- 文案全部走 `zh.ts` / `en.ts` 的 `proto.*`（224 个键，双语占位符一致），随原型一起删除；
- 仍需在原型上确认的细节见 §8。

**确认之后**：把 `proto-ui.tsx` 里通过的部分抽到 `components/`（F1），再按 F2→F5 逐页替换，
每页 parity 清单过一遍；原型路由最后随 F6 一起删除。
