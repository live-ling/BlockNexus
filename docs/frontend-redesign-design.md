> 本文是 F1 之前的**设计确认稿**：先定「有哪些页面、每页干什么、怎么排、用什么组件」，
> 再写原型，最后逐页接数据。**本轮不改现有页面代码**。
>
> 依据：`docs/frontend-redesign-audit.md`（盘点）、`docs/instance-page-refactor.md`（实例页）、

## 0. 一句话方向

**这是桌面应用，不是网站。** 基准窗口 **1000×720**（外壳最小 960×640，系统原生标题栏），
内容从窗口左边贴到右边，结构靠**固定区域 + 分隔线 + 密集表格**，不靠居中窄栏和大段留白。

**已确认的六个方向**（2026-10-21 二次修订，据此做出 `/proto` 原型，见 §7）：

| 项 | 结论 |
|---|---|
| 导航 | **底部居中悬浮导航**（沿用现有 `ExpandableActionBar`），不做左侧栏；页头只放标题与页面操作，**不显示 SSE/在线数/安装进度/版本** |
| 窗口基准 | **1000×720** |
| 列表呈现 | **只要卡片**：表格/列表视图取消；卡片内部不画分割线，信息给全（核心/玩家/内存/时长/端口/地址） |
| 筛选 | **默认隐藏**：右边缘中部一个竖标签，点开是 320px 抽屉，搜索/状态/服务器/排序都在里面 |
| 设置页 | 左侧目录（锚点跳转）+ 右侧**一次性列出全部设置项**；分区之间只有一条分隔线，不套卡片边框 |
| 实例页主区 | Tab 工作台 + 底部终端 Dock（本轮先不动） |
| 密度 | 正文 13px、列表行 36、工具栏 44、Tab 40、区块间距 8、面板内边距 12 |
| 删除 | **不设「危险」页**：删除就放在对象自己的页面里（实例→控制面板基础页底部；服务器→设置页末尾一节） |
| 原型形态 | app 内隐藏路由 `/proto`，真实 shadcn 组件 + mock 数据 |

与现状最直观的差别：

| 现状（网页思维） | 目标（应用思维） |
|---|---|
| `mx-auto max-w-5xl/[1400px] px-5 pt-7 pb-28` 居中窄栏 | 全宽铺满，页面内边距 16~20，滚动区底部只留悬浮导航的 80 |
| 卡片网格 `minmax(300~320px,1fr)`，宽屏碎成窄长卡 | 数据表 / 分区面板；列宽按内容，一列到底 |
| 搜索框、表单、资源列一律拉满可用宽度 | 搜索 224、表单组 620、资源列 140；**控件宽不过内容** |
| 底部悬浮胶囊导航（手机味，但好用） | 保留悬浮导航，只把状态信息挪进页头，不再额外压一条状态栏 |
| 空态 `py-16` 大留白、区块间 `gap-5` | 空态一行文案＋操作；区块间 8，字段间 6 |

**保留不动**：shadcn/Radix + Tailwind、现有配色与字体（Geist）、虚拟滚动/日志组件、所有后端接口。

## 1. 窗口骨架（AppShell）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ PageHeader 52px  标题 · 副标题                                  [页面操作]    │
├──────────────────────────────────────────────────────────────────────────────┤
│ 内容区 padding 20，全宽，独立滚动（底部留 80 给悬浮导航）                    │
│  ListPage   : 卡片网格 + 右边缘「筛选」竖标签（抽屉默认隐藏）     ⟂ 筛选       │
│  DetailPage : 指标条 64 + Tab 40 + 主从区 + Dock（实例页本轮不动）            │
│  SettingsPage: 左侧目录 190（sticky）+ 右侧全部设置项（分区不画线）          │
│                                                                              │
│                   （底部居中悬浮导航：overlay，不占布局）                     │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **无自绘标题栏**：外壳用系统标题栏，网页里不再画一条假 titlebar（避免双标题栏）。
- **底部悬浮导航**：直接复用现有的 `ExpandableActionBar`（logo / 实例 / 服务器 / 设置），
  距底 20，`z-40`；内容滚动区留 `pb-24`，设置页给保存条上方留 64，避免被压住。
  实例工作台**不显示导航**（页面内有返回与终端），与现状一致。
- **PageHeader**：每页唯一，只放返回（详情页）、标题、副标题、页面自己的操作。
  **不再显示 SSE/在线数/安装进度/版本更新**——这些常驻状态在页头反而占宽度、抢注意力。
- **筛选入口**：列表页右边缘中部一个竖标签，**平时只露出 7px 贴边隐藏**，鼠标靠近才滑出（`group-hover` 位移，
  0.2s）；点开右侧 320px 抽屉。默认关着，卡片区因此多出整行宽度。
- **外壳高度链（踩过的坑）**：`<main>` 必须写 `min-h-0 overflow-hidden`。它是 column flex 的子项，
  自动最小高度会取「内容高度」——实测不写时 main 被撑到 1181px（窗口只有 578），
  子页面里的 `overflow-auto` 于是拿到内容高度，`scrollHeight === clientHeight`，
  **滚动条不存在、目录跳转也永远滚不动**（`scrollTop` 恒为 0）。列表页当时因为内容恰好一屏没暴露。
- **危险横幅**（暴露且未开鉴权）仍置顶，压到 24px 单行，不挡内容。

- **只要卡片**：表格/列表视图取消，卡片自适应 `minmax(320px,1fr)`；搜索筛选不再常驻。
- 卡片内容：**左上角实例图标**（实例没有自定义图标时用 `Server` 图标占位）、名称、备注（无则服务器名）、
  **右上角状态徽章**、核心+版本、服务器、玩家、内存（条+数值）、运行时长、端口、**最近备份**（整行）、连接地址。
  卡片内部不画分割线，靠 2 列键值对的间距分组；状态只由右上角徽章表达，不再有独立圆点。
- 卡片本身不启停（防止大视野误点），点卡片进实例页；hover 出「打开」。
- 筛选抽屉（默认隐藏）：搜索、状态（全部/运行中/已停止/异常）、服务器、排序、重置。
- 空态：一行文案 + 「重置」；数据仍沿用并发上限 6、20s 玩家轮询、SSE 增量。

## 4. 尺寸与密度令牌

桌面应用的关键不是「小」，是**稳定、可预期、无空隙**。统一写进 `@theme`（Tailwind v4）与页面常量：

| 令牌 | 值 | 说明 |
|---|---|---|
| `--header-h` | 52 | PageHeader |
| `--toolbar-h` | 44 | 列表工具栏 |
| `--tab-h` | 40 | 页内 Tab |
| `--row-h` | 36（表格）/ 40（两行列表项） | 表格与列表行 |
| `--pad-page` | 16~20 | 内容区外边距 |
| `--pad-panel` | 12 | 面板内边距 |
| `--gap-block` | 8 | 区块之间（现状 gap-5=20 太大） |
| `--gap-field` | 6 | 字段之间 |
| `--nav-clear` | 96 | 悬浮导航让位（各页滚动区 `pb-24`；设置页不再有底部保存条） |
| `--card-pad` | 14 | 卡片内边距 |
| `--card-gap` | 12 | 卡片间距（网格 gap 12） |
| `--drawer-w` | 320 | 右侧筛选抽屉宽度 |
| `--form-w` | 620 | 设置表单组上限（两列各约 300） |
| 搜索框 | 224 | 抽屉里占满 320 的内容宽，页面里不常驻 |
| 字号 | 13 正文 / 11.5 次要 / 12 等宽数字 | 现状 14 正文偏网页 |
| 圆角 | 8（卡片/面板）/ 6~8（控件）/ 10（浮层） | 统一，不再混 12/16 |
| 分隔 | 1px `border-border` 只出现在页面/浮层边界；**卡片内部与设置分区都不画线** | 靠间距与字号分组；阴影只给浮层 |

**宽度策略**：列表页是卡片网格（`minmax(320px,1fr)` / 服务器 340），宽度由卡片和间距自己决定；
设置页表单 ≤620 靠左；按钮/输入/资源条一律按内容定宽，不 `w-full` 拉满一列。
多余宽度留给空白，而不是把控件拉宽——「横向组件过宽」正是二次反馈里的主要问题。
**禁止**再出现「页面级 `max-w-*` + `mx-auto`」。

## 7. 原型（已落地：`/proto`）

打开方式：面板启动后访问 **`http://127.0.0.1:<端口>/proto`**（已登录/未登录都可以，原型不读登录态、不发请求）。
支持 `?screen=server-settings` 直达某一屏（`instances` / `servers` / `server-settings` / `instance` /
`panel-settings` / `login`），切换屏幕时会同步写回地址，方便截图与发人看。
页头右侧的 `PROTO` 下拉也可切屏；真实应用里没有这一项。

| 文件 | 作用 |
|---|---|
| `web/src/prototype/index.tsx` | 原型入口与屏幕切换 |
| `web/src/prototype/shell.tsx` | 悬浮导航 / PageHeader / 屏幕切换器 |
| `web/src/prototype/proto-ui.tsx` | 原语：Panel / KV / Field / FormGrid / SearchInput / Select / Segmented / EmptyState |
| `web/src/prototype/filter-drawer.tsx` | 右边缘竖标签 + 320px 筛选抽屉 |
| `web/src/prototype/settings-layout.tsx` | 设置页骨架：左目录锚点 + 右侧全量分区（无卡片） |
| `web/src/prototype/mock.ts` | 假数据（4 台服务器、7 个实例、玩家、日志、备份） |
| `web/src/prototype/screens/*.tsx` | 实例总览 / 服务器列表 / 服务器设置 / 实例工作台 / 面板设置 / 登录 |

要点：

- 全部用真实 shadcn 组件（Button/Dialog/Sheet/Switch + 现有 `ExpandableActionBar`），不引入新依赖；
- **列表只有卡片**：卡片内不画分割线；筛选默认隐藏，右边缘竖标签平时只露 7px、鼠标靠近滑出；
- **设置页左目录（sticky）+ 右侧全量分区**：整页一个滚动容器（鼠标在目录上也能滚），
  分区之间不画线、只留间距，跳转用 `scrollTo` 计算偏移；
- 服务器卡片带 Java 主版本（mock：21 / 21 / 17 / —），资源三条（CPU/MEM/DISK）垂直排列；
- 页头不再显示 SSE / 在线数 / 安装进度 / 版本更新；实例页本轮未改动（仍是上一版的 Tab + Dock + 控制面板）；
- 文案全部走 `zh.ts` / `en.ts` 的 `proto.*`（212 个键，双语占位符一致），随原型一起删除；
- 布局回归可以不信肉眼：起一个静态服务 + 无头 Edge（`--headless=new --remote-debugging-port=9222`），
  用 CDP 量 `clientHeight / scrollHeight / scrollTop`、模拟 `mouseMoved` 与点击，
  本轮「设置页滚不动」就是这么做定位到 `main` 高度没被约束的；
- 仍需在原型上确认的细节见 §8。

**确认之后**：把 `proto-ui.tsx` 里通过的部分抽到 `components/`（F1），再按 F2→F5 逐页替换，
每页 parity 清单过一遍；原型路由最后随 F6 一起删除。

## 8. 待确认（原型上仍需点头的细节）

1. 卡片网格在 1000 宽下是 2 列（`minmax(320px,1fr)`）——够不够密，要不要降到 300 挤 3 列；
2. 卡片里给了 6 项键值（核心/服务器/玩家/时长/内存/端口）+ 地址行，是否还需要别的内容（如 frp 徽标、Java 版本）；
3. 右边缘「筛选」平时只露 7px 是否够发现——需要更宽（10~12px）或加一条竖排小字提示吗；
4. 设置页表单 620 靠左、右侧留白，接受吗（另一种是整体居中）；
5. 服务器卡片的拖动排序怎么放（拖拽手柄 / 抽屉里的「手动排序」+ 上下箭头）；
6. 设置页去掉分割线后，靠「标题字号 + 28px 间距」分区是否够清楚；
7. 实例工作台本轮未动，下一轮按 `instance-page-refactor.md` 的 P0–P4 落地。
