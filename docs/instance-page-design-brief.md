## 0. 一句话

桌面端（基准窗口 1000×720）的**单实例工作台**：顶部一条 44px 指挥条 + 3 张固定指标卡 +
5 个页签（概览/玩家/文件/配置/维护）+ 整页底部可拖拽的深色终端 Dock；设置类操作全部收进

规模数据：`instance-detail.tsx` **2157 行 / 93 KB**，`useState` 30、`useEffect` 13、
`useCallback` 7、`useRef` 2；`instanceDetail.*` i18n 键 **250 个**（zh/en 双语）。

## 1. 硬性布局约束（设计时可以改视觉，但这些行为不能破）

1. **整页不滚动**：根容器 `h-screen + overflow-hidden`，指挥条/指标条/页签永远在位；
   只有终端日志、玩家名单、页签内容这类内部区域各自 `overflow-y-auto`。
2. **高度链固定**：`100vh → flex-1 → min-h-0`，不允许任何一栏的高度反过来由内容决定
   （历史上这样做过，终端高度失控）。
3. **防跳动**：指标卡高度写死（当前 104px）；主操作按钮（启动↔停止）宽度按最长文案取齐
   （`min-w-[124px]`），否则右对齐的按钮组会把「更多」推走。
4. **深色终端是页面里唯一的深色面**，浅色/深色主题下都保持 `#0B0B0F`，用来和内容面区分。
5. **颜色只走语义令牌**（`bg-card` / `border-border` / `text-muted-foreground`…），
   硬编码的 Tailwind 色只允许用于「状态」（emerald/amber/red）和终端配色。
6. **文案全部走 i18n**（`zh.ts` / `en.ts` 键与占位符必须一致）。
7. 不改后端接口；`Ctrl+\`` 切换终端、`Esc` 关弹层等键盘行为保留。

## 3. 逐区功能清单

### 3.1 指挥条 Header（44px，`bg-background`，下边框）

| 元素 | 行为 |
|---|---|
| 返回按钮 | 回服务器详情/实例列表 |
| 实例图标 | 38×38 圆角 10px，emerald 淡底 + 边框；优先显示游戏内 `server-icon.png`，缺省回退**等距立方体** SVG |

| 切换实例 ▾ | 同服务器实例下拉：状态圆点 + 名称 + 当前项打勾；多于 1 个实例才出现 |

### 3.2 指标条（3 张卡，各 104px）

| 卡 | 主值 | 辅助行 |
|---|---|---|
| 在线玩家 | `4 / 20` | 进度条（emerald；不可达=amber；空闲=灰）或原因文字（未运行/启动中/查询中/无响应） |
| 运行时长 | `3h12m` | 状态胶囊「运行中」；未运行时改为「上次运行/失败原因(红色)/正常停止」 |
| 内存上限 | `6.0 GB`（运行中才显示） | 运行中：**主机**内存占用条 + `used / total`；未运行：「上限 6.0 GB · 已释放」 |

### 3.3 页签

`概览 | 玩家 | 文件 | 配置 | 维护`，5 个**固定存在**（不随运行态增删，避免布局跳动）。
未激活的页签用 `display:none` 保活（切回不丢状态/日志）。

#### 概览（默认）
两列（`minmax(0,2fr) / minmax(0,1fr)`）：

**左列「状态与环境」卡**
- 标题「状态与环境」+ 右上角核心胶囊（如 `Paper 1.21.4`）
- 失败时：红底提示条（失败 + 错误原因 + 「控制台」跳转）；正常时一行摘要（状态 · 玩家 x/y · 备注）
- **连接地址行**：等宽地址 + 复制按钮 + `frp` 徽标（已绑定时）+ 右侧域名检测状态
  （未配置/未运行/检测中/IP:端口 · TCP xx ms · SRV/失败原因）+ 重新检测按钮
- Java 缺失或 <21 时出现 **Java 安装条**（版本选择 21/17 + 安装）
- 3 格元数据：运行时长 / Java 主版本 / 端口
- 快捷操作行（7px 高的小按钮）：立即备份、打开终端、文件、server.properties、地图、重启

**左列「MOTD」卡**
- 标题 + 副标题、复制按钮
- **深色预览块**（`#0B0B0F` + zinc-200 等宽字）——整页唯一深色内容面，和终端呼应
- 底部：正版验证 开/关 + 「编辑」→ server.properties

**右列「最近事件」卡**
- 标题 + 副标题 + 状态胶囊（点 + 状态文字）
- 时间轴列表：最多 8 条（从控制台尾部筛 ERROR/Exception/上下线/备份/Done 等），
  错误行红点红字、其余灰点灰字；空态一行文案
- 底部：`N ERROR` 计数 + 「打开控制台 ›」

**世界地图**：默认收起，点快捷操作「地图」就地展开（`h-[46vh]`）。

#### 玩家
左卡 320px + 右侧聊天记录：

- 左卡：标题「玩家」+ `4 / 20` 胶囊、进度条、玩家列表
  - 每行：**首字母彩色头像**（8 色板按名字哈希）、等宽玩家名、`本次 1h02m · 累计 12h`、
    hover 出现 `⋮` 菜单：踢出 / 封禁 / 封禁 IP（红）/ OP / DEOP
  - 底部两个次级按钮：玩家统计、封禁目录
  - 空态：图标 + 「未运行 / 暂无玩家」+ 一行提示
- 右侧：聊天记录面板（关键词搜索、玩家名过滤、翻历史页、贴底自动滚、记录关闭时提示）

#### 文件
整块卡片内嵌文件管理器：懒加载目录树、文本预览/编辑、分块上传队列（可续传）、
下载/删除/新建文件夹/复制/剪切/粘贴/重命名/压缩/解压、多选批量操作。

#### 配置
2~3 列卡片网格：
- `server.properties`：端口 / 最大玩家数 / 正版验证 + 「打开」
- 插件配置：有 `plugins/` 或 `config/` 才可点（否则禁用 + 说明）
- Mod：打开 Mod 管理器（列表 / 启用-禁用 / 删除 / 拖拽上传），装了 Spark 时附注
- 实例编辑（跨 3 列）：核心 / 内存上限 / 备注 + 「编辑」→ 完整编辑对话框

#### 维护
2 列网格：
- 自动化卡：自动重启（崩溃拉起 + 定时任务摘要）「编辑」；定时备份（计划摘要）「编辑」

- 诊断卡（跨 2 列）：AI 日志分析 / Spark 性能两个开关（仅运行中可用），下方就地展开面板 `h-[46vh]`

## 5. 当前主题色（设计必须基于这套令牌）

### 5.1 主题机制

- `next-themes`，`attribute="class"`，**默认浅色**（`defaultTheme="light"`），`enableSystem=false`，
  storage key `blocknexus-theme`；深色靠 `.dark` 类。
- 字体：**Geist Variable**（`--font-sans`），日志/地址/端口/玩家名用等宽。
- 圆角：`--radius: 0.625rem`（10px），派生 sm 6 / md 8 / lg 10 / xl 14 / 2xl 18。
- 色板本质是 **shadcn 中性灰（zinc 系）**，**没有品牌主色**——primary 就是「近黑」，
  强调靠状态色（emerald/amber/red）。这是有意为之：避免每个页面跳一块亮蓝。

## 6. 已知问题 / 可设计空间（不是需求，是现状缺口）

1. **控制面板太挤**：模态仅 860px 宽、`min-h-[360px]`，6 组内容挤在窄框里；
   计划放大到 `min(1160px,94vw) × min(760px,86vh)`、左导航 180、基础/网络改两列。
2. **终端双数据源**：页面 5s 轮询 `tail=200`（喂概览事件与 Dock 摘要）+ ConsolePanel 自己
   `tail=300` + SSE；两套可能不同步，是结构性问题（不是视觉问题）。
3. **入口重复**：frp 在控制面板「网络」组与 `InstanceFrpDialog` 各有一套（后者已无触发点）；
   属性入口在「概览 MOTD」「配置」「控制面板基础」三处；统计/封禁在「玩家」页与控制面板两处。
4. **概览左卡信息过载**：核心、状态、地址、域名检测、Java 提示、3 格元数据、6 个快捷操作
   全在一张卡里。
5. **Dock 收起态不能输入命令**（设计稿要求可以）。
6. **空态/加载态简陋**：加载只有一行文字，无骨架屏、无错误边界。
7. **缺 CPU 指标**（接口未提供，设计时不要假定有）。
8. **单文件 2157 行 / 30 个 state**：任何视觉改动都要在巨型组件里定位，建议设计时按
   「Header / MetricStrip / Tabs / 各页签 / Dock / 控制面板」给出**可拆分的分区规格**。
