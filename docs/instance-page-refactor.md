# 实例详情页与设置页 · 排版规格（2026-10-25 实施版）

> 本文取代 2026-10-21 的三栏版盘点与重构方案：页面已经落地为
> 「Header + 5 页签（指标条并入概览）+ 概览内嵌终端」，控制面板放大为 1160×760 四组。
> 事实清单见 [instance-page-design-brief.md](./instance-page-design-brief.md)（采集于改版前，行为约定仍有效）。

## 0. 一句话

桌面工具式单实例工作台：44px 指挥条 + 5 页签；**指标条与终端都住在「概览」页签里**，
其它页签把空间留给工作区；设置类操作收进 1160×760 的控制面板模态（4 组），
地图 / AI 分析 / Spark 在全屏浮层里看。

## 1. 频次分层（所有新功能先过这张表再决定放哪）

| 层 | 判定 | 去处 | 例子 |
|---|---|---|---|
| L0 常驻 | 秒级关注 / 打断告警 | Header、终端头部 ERROR 计数 | 状态呼吸灯、启动/停止 |
| L1 页签工作区 | 每天用 | 5 页签 | 玩家名单、文件、备份列表、终端 |
| L2 条件条 | 需要上下文的告警 | 页签内通栏，无事零高度 | 失败原因、Java 缺失 |
| L3 全屏浮层 | 重内容（地图/长文结果） | Esc 关闭的全屏 dialog | 地图、AI 分析、Spark |
| L4 模态 | 低频表单/确认 | DialogShell | 编辑实例、重装、控制面板 |
| L5 二级菜单 | 低频动作 | `⋮` | 重启、备份、控制面板、地图、属性 |

**入口唯一**：属性/插件/Mod/完整编辑 → 配置页签；frp → 控制面板·网络；统计/封禁 → 玩家页签；
备份 → 维护页签（Header ⋮「备份」开创建弹窗）。

## 2. 实例页分区

```
Header 44：返回 · 图标 · 名称/状态/延迟/切换实例 · 服务器·主机·Agent ｜ 启停 + ⋮
Tabs 40 ：概览 ｜ 玩家 ｜ 文件 ｜ 配置 ｜ 维护
内容 flex-1（各页签自己滚）：
  概览：MetricStrip 72 → 条件条(0-32) → 地址行卡 → [快捷操作行 ｜ 右：最近事件]
        → 终端深色卡（状态 + ERROR + 搜索 + 清空 + 日志 + 命令输入，flex-1 填满）
  玩家：左 320 名单 + 右聊天
  文件：内嵌文件管理器
  配置：单卡 4 行式入口（属性 / 插件 / Mod / 编辑实例，各 44px）
  维护：自动化(1fr) ｜ 备份列表(2fr) → 诊断两行入口（结果进全屏浮层）
```

- **指标条只属于概览**：玩家/时长/内存是「现在怎么样」的答案，不随页签常驻（省 96px）。
- **终端取代 MOTD 预览 + 底部 Dock**：概览左列主内容面就是终端（页面唯一深色面），
  收起态输入/拖拽高度/`Ctrl+\`` 全部废除——不再需要收起，就没有收起态的问题。
- MOTD/元数据（核心·时长·Java·端口·备注）压缩为地址卡下的 caption 行。
- 快捷操作 3 个（备份/文件/重启）+ ⋮（地图/属性）；「打开终端」删除（终端就在下方）。

## 3. 控制面板（1160×760，四组）

| 组 | 内容 |
|---|---|
| 基础信息 | 内存上限 + 备注（两列）+ 只读：核心/端口/正版验证/MOTD |
| 网络与端口 | 绑定域名 ┇ frp（本地端口只读、远程端口、状态、启用/解除） |
| 自动化 | 自动重启、定时备份（带启用点，跳原对话框） |
| 危险操作 | 面板安装、重装核心、删除实例（运行中 amber 警告） |

玩家组（统计/封禁）与备份组已删——与页签完全重复；`InstanceFrpDialog` 死代码已删。

## 4. 设置页（面板设置 + 服务器设置，同一套骨架）

`SettingsLayout`：左目录 190 + 右侧全量分区；**分区不套卡片**——13px 区块标题 + 28px 间距分组，
颜色只留给状态（StateChip/错误）。表单 620 封顶（面板设置内容列 680），控件不拉满。

- 字段结构：11.5px 标签在上 → 控件 → **提示在控件下方**（保证同一排输入框顶边对齐）。
- 低频下沉：更新日志 → 右抽屉（Sheet）；DDNS 的 TTL/间隔/取址方式 → 「高级设置」折叠。
- 分区：面板设置 6 组（访问与安全 / 网络 / 通知 / AI / 更新 / 外观与关于），
  主题切换从页头搬进「外观与关于」；服务器设置 5 组，危险区用红色标题 + 上分隔线表达。

## 5. 守住的硬约束（不变）

1. 整页不滚动：`h-screen + overflow-hidden`，高度链 `100vh → flex-1 → min-h-0`；
2. 指标条高度写死 72px、主操作按钮 `min-w-[124px]` 防跳动；
3. 颜色只走语义令牌，状态色（emerald/amber/red）除外；终端保持 `#0B0B0F` 唯一深色面；
4. 文案全部 i18n（zh/en 键一致）；不改后端接口；`Esc` 关浮层保留。

## 6. 已知取舍

- 「收起态命令输入」随 Dock 一起废除：终端常驻概览后，输入框永远可见（未运行时禁用）。
- 命令历史/自动跟随/1500 行缓冲等由 ConsolePanel 提供，未动。
- 终端双数据源（页面 5s 轮询 tail=200 喂事件/计数 + ConsolePanel 自拉 SSE）是结构性问题，
  本次未合并（不属于排版范畴）。
