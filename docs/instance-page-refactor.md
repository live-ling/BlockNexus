# 实例详情页与设置页 · 排版规格（2026-10-25 实施版）

> 本文取代 2026-10-21 的三栏版盘点与重构方案。**2026-10-25 又做了两轮调整**：
> ① 日志单源化 / 状态收口 / 异常态（见 `instance-console-next-steps.md`）；
> ② 概览改为「终端优先 + 状态驱动」，控制面板修掉宽度被压成 384px 的 bug。
> 下面第 2、3 节的排版描述已按现状更新；事实清单见 [instance-page-design-brief.md](./instance-page-design-brief.md)。

## 0. 一句话

桌面工具式单实例工作台：44px 指挥条 + 4 页签；**指标条与终端都住在「概览」页签里**，
其它页签把空间留给工作区；设置类操作收进 1160×760 的控制面板模态（4 组），
地图 / AI 分析 / Spark 在全屏浮层里看。

## 1. 频次分层（所有新功能先过这张表再决定放哪）

| 层 | 判定 | 去处 | 例子 |
|---|---|---|---|
| L0 常驻 | 秒级关注 / 打断告警 | Header、终端头部 ERROR 计数 | 状态呼吸灯、启动/停止 |
| L1 页签工作区 | 每天用 | 4 页签 | 玩家名单、文件、配置/备份列表、终端 |
| L2 条件条 | 需要上下文的告警 | 页签内通栏，无事零高度 | 失败原因、Java 缺失 |
| L3 全屏浮层 | 重内容（地图/长文结果） | Esc 关闭的全屏 dialog | 地图、AI 分析、Spark |
| L4 模态 | 低频表单/确认 | DialogShell | 编辑实例、重装、控制面板 |
| L5 二级菜单 | 低频动作 | `⋮` | 重启、备份、控制面板、地图、属性 |

**入口唯一**：属性/插件/Mod/完整编辑 → 「配置与维护」页签；frp → 控制面板·网络；统计/封禁 → 玩家页签；
备份 → 「配置与维护」页签（Header ⋮「备份」开创建弹窗）。

## 2. 实例页分区

```
Header 44：返回 · 图标 · 名称/状态/延迟/切换实例 · 服务器·主机·Agent ｜ 启停 + 重启 + ⋮
Tabs 40 ：概览 ｜ 玩家 ｜ 文件 ｜ 配置与维护
内容 flex-1（各页签自己滚）：
  概览·运行态：MetricStrip 72 → 条件条(0-32) → 地址行 32 → 终端全宽（flex-1，占视口 ~67%）
  概览·停止态：条件条 → 中央状态/原因 + 启动(44) + 查看最近日志（终端默认收起）
  玩家：左 320 名单 + 右聊天
  文件：内嵌文件管理器
  配置与维护：左列＝配置入口(4 行) + 诊断；右列＝备份列表 + 自动化（0.92fr / 1.08fr）
  维护：已并入「配置与维护」，不再有独立页签
```

- **配置与维护合并的原则**：左列是「改什么」（属性/插件/Mod/编辑 + AI/Spark 诊断），
  右列是「数据与自动运行」（备份列表 + 自动重启/定时备份）。不是把两张页面上下拼起来。
- **终端是概览唯一主内容面**：右栏「最近事件」卡已删除（它只是日志的重复摘录），
  其能力改为终端工具行的「仅看错误」开关；地址压成一行 32px，快捷操作行删除
  （文件→页签、备份→⋮、重启→Header 常驻按钮）。
- **指标条只在运行态出现**：停止/失败时不再用三格「—」占位，改为状态 + 原因 + 启动。
- MOTD/元数据（核心·时长·Java·端口·备注）压缩为地址行右侧的 caption。
- 头部：主操作 36px（停止/启动）、重启 36px 常驻、⋮ 收地图/属性/控制面板/备份。

## 3. 控制面板（1160×780，四组，自适应双栏）

| 组 | 内容 | 布局 |
|---|---|---|
| 基础信息 | 内存上限 + 备注（2 列）+ 只读：核心/端口/正版验证/MOTD | 表单 1fr ｜ 只读侧栏 320 |
| 网络与端口 | 域名 ┇ frp（本地端口只读、远程端口、状态、启用/解除） | 两张卡并排（≥1280） |
| 自动化 | 自动重启、定时备份（带启用点，跳原对话框） | 两张卡并排 |
| 危险操作 | 面板安装、重装核心、删除实例（运行中 amber 警告） | 单列，最大 880 |

⚠ **宽度踩过的坑**：`DialogContent` 基础类里有 `sm:max-w-sm`（24rem = 384px）。
只写 `max-w-none` 会被 sm 断点压回 384px——面板"一直很窄"的真正原因。
必须写成 `max-w-none! sm:max-w-none!`，否则 w-[1160px] 不生效。

玩家组（统计/封禁）与备份组已删——与页签完全重复；`InstanceFrpDialog` 死代码已删。

## 4. 设置页（面板设置 + 服务器设置，同一套骨架）

`SettingsLayout`：左目录 190 + 右侧全量分区；**分区不套卡片**——13px 区块标题 + 28px 间距分组，
颜色只留给状态（StateChip/错误）。表单 760 封顶（面板/服务器设置内容列 1160），控件不拉满；
并排卡片（网络、通知、更新、外观）在 lg 断点两列。

- 字段结构：11.5px 标签在上 → 控件 → **提示在控件下方**（保证同一排输入框顶边对齐）。
- 低频下沉：更新日志 → 右抽屉（Sheet）；DDNS 的 TTL/间隔/取址方式 → 「高级设置」折叠。
- 分区：面板设置 6 组（访问与安全 / 网络 / 通知 / AI / 更新 / 外观与关于），
  主题切换从页头搬进「外观与关于」；服务器设置 5 组，危险区用红色标题 + 上分隔线表达。

## 5. 守住的硬约束（不变）

1. 整页不滚动：`h-screen + overflow-hidden`，高度链 `100vh → flex-1 → min-h-0`；
2. 指标条高度写死 72px、主操作按钮 `min-w-[124px]` 防跳动；
3. 颜色只走语义令牌，状态色（emerald/amber/red）除外；终端保持 `#0B0B0F` 唯一深色面；
4. 文案全部 i18n（zh/en 键一致）；不改后端接口；`Esc` 关浮层保留。

## 6. 已知取舍

- 「收起态命令输入」随 Dock 一起废除：终端常驻概览后，输入框永远可见（未运行时禁用）。
- 命令历史/自动跟随/1500 行缓冲等由 ConsolePanel 提供；日志数据源已统一到
  `lib/instance-log-store.ts`（历史一次拉取 + SSE 实时追加 + 断线补偿），
  **页面不再有 5s `tail=200` 轮询**。断线补偿刻意不按内容去重（MC 重复行是常态）。
- 概览的「仅看错误」是显示过滤，不改缓冲区；ERROR 徽章只统计**本次运行**（`runStart`）。
- 停止态日志默认收起：停止后没有实时流，保留一大片旧日志反而挤掉「启动」。
