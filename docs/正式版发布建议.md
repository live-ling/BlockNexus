## What this is
A local-first Minecraft server management panel (web UI) plus a remote Agent for managing Minecraft instances over SSH or a secure websocket channel. 解决的是在本地运行面板、通过 SSH/Agent 自动安装 Java / Paper 等服务器核心、管理多个实例（启动/停止/备份/文件管理/玩家统计/聊天记录/AI 日志分析）的运维痛点，目标用户是 Minecraft 服主与小型托管者。当前版本标签与 README 显示项目处于活跃开发（当前 package.json version: 0.6.0），未到正式 1.0.0，许多设计与文档已经详细但仍需更多真实用户反馈和测试覆盖。

### Stack
- Language(s): JavaScript (Node.js) for backend/agent, TypeScript + React for frontend
- Framework / runtime: Node.js (>=18) + Express (panel), Vite + React (web)
- Notable libraries: express, ws, ssh2, nodemailer (panel/agent tooling); Vite, React, Tailwind on frontend

## How it's organized
```
package.json                npm scripts, main=panel/server.js, engines node >=18
README.md                  产品说明、快速开始、架构图与安全说明
panel/                     面板后端逻辑（Express + 任务调度 / SSH / 更新 / Agent 协议）
  server.js                主入口 HTTP + API + 静态托管
  agentlink.js             AgentHub / 加密通道相关
  ssh.js                   SSH 自动安装/上传 agent 脚本
  update.js                应用内更新逻辑
agent/                     单文件 agent 及构建、测试脚本（可直接下载 agent.js）
  agent.js                 运行在远端服务器的 agent 主体
  build.js                 agent 构建脚本
  many test-*.js           agent 的大量单元/集成/场景测试脚本
web/                       前端（React + TypeScript + Vite），build 输出放 web/dist
data/                      运行时配置示例（data/config.example.json），持久化数据目录约定
docs/                      详细设计、路线图、开发文档（development.md、iteration-roadmap.md 等）
scripts/                   打包、Windows EXE 构建、updater、launcher 脚本
images/ vendor/            资源和第三方/辅助文件
```

How it fits together:
- panel/server.js 提供 HTTP API、静态托管已构建的前端，并负责与 Agent 的管理（更新、任务、SSE 事件等）。  
- agent/agent.js 是可在远端运行的单文件 Javascript agent，Agent 与面板之间用 token + 可选 TLS 的 websocket 进行双向认证与事件/控制。  
- web/ 是 SPA（Vite + React），通过 build 生成 web/dist，由面板托管；scripts/ 中有打包与生成便携 exe 的工具。数据（config.json、实例目录、备份）由面板与 Agent 在约定路径下读写。

## How to run it
Shortest path from clone to running (from README + package.json):
1. 环境要求：Node.js >= 18
2. 安装与构建前端：
   ```
   npm install
   npm run build:web    # 在 web/ 下运行 vite build（由根的 script 封装）
   ```
3. 启动面板：
   ```
   npm start            # 等价于 node panel/server.js
   # 或直接
   node panel/server.js --host 127.0.0.1 --port 3080
   ```
4. 常用启动参数 / env:
   - --host / BLOCKNEXUS_HOST (默认 127.0.0.1)
   - --port / BLOCKNEXUS_PORT (默认 3080)
   - --tls-cert / --tls-key (或 BLOCKNEXUS_TLS_CERT / BLOCKNEXUS_TLS_KEY)：面板自身 HTTPS
   - BLOCKNEXUS_PASSWORD：可在启动时设密码（建议对外暴露时必设）
   - --trust-proxy / --secure-cookies：反向代理场景相关
5. 快速测试 Agent（手动安装示例，README 提供）：
   ```
   curl -fsSL http://127.0.0.1:3080/agent.js -o agent.js
   node agent.js --panel ws://127.0.0.1:3080 --token <token> --id <serverID>
   ```
6. Releases: README 提到便携包（portable zip）可直接下载并双击运行，适合给非开发用户做早期试用。
